The writer reads the brief, writes the post in WordPress (blog.nxtmt.ventures, blog_id 249186184), schedules it for the date/time in the header, then updates the **Status** line to `WRITTEN AND SCHEDULED — WordPress post <id>, YYYY-MM-DD 08:00 America/Chicago`. The sync plugin commits the markdown into `client/content/blog/`; nobody hand-commits posts._
