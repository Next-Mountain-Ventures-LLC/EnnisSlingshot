## Facts & sources to cite
- Tex. Transp. Code §521.085(b): a license holder may operate "an autocycle as defined by Section 501.008" — https://texas.public.law/statutes/tex._transp._code_section_521.085
- Tex. Transp. Code §501.008(a): autocycle definition (3 wheels, seat belts, steering wheel, non-straddle seating, federal motorcycle safety certification) — https://texas.public.law/statutes/tex._transp._code_section_501.008
- Tex. Transp. Code §661.0015(b): autocycles are treated as motorcycles for helmet-law purposes unless the cab is partially/fully enclosed — https://texas.public.law/statutes/tex._transp._code_section_661.0015
- Tex. Transp. Code §661.003: under-21 helmet mandate; 21+ exemption requires a completed training course or qualifying health insurance; $10–$50 fine; no stop-solely-to-check — https://texas.public.law/statutes/tex._transp._code_section_661.003
- Texas DPS, "New Law Establishes Definition, Rules for Autocycles": confirms Class C license covers autocycle operation — https://www.dps.texas.gov/node/1439
- SB 449 enrolled text (84th Legislature, effective May 22, 2015) — the bill that created the autocycle classification — https://capitol.texas.gov/tlodocs/84R/billtext/html/SB00449E.htm
- Powersports Business, "Three states reclassify Slingshot licensing requirements" (Jun 21, 2017) — historical count context — https://powersportsbusiness.com/top-stories/2017/06/21/three-states-reclassify-slingshot-licensing-requirements/
- Street Bikers World (Apr 12, 2025) — the article whose headline table conflicts with its own body text on Texas requirements; cited as the example of live misinformation to correct, not as an authority — https://streetbikersworld.com/states-that-require-a-motorcycle-license-for-a-slingshot/
